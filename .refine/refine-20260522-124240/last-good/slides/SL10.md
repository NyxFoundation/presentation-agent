# 監査が届くのは5分類中3つだけ

<div class="text-sm opacity-60 mb-6">DeFi脆弱性の5カテゴリ — A価格 ／ B精度 ／ D ロジック ／ C運用設定 ／ E経済</div>

<div class="flex justify-center mt-4">

| カテゴリ | 内容 | 監査カバレッジ |
| :--- | :--- | :--- |
| A | 価格操作(Flash Loan等) | ✓ カバー |
| B | 精度・丸め(例:Cetus) | ✓ カバー |
| D | ロジック一貫性ドリフト | △ 部分 |
| **C** | **運用・デプロイ設定(例:KelpDAO)** | **✗ 外側** |
| **E** | **経済モデル(例:Terra-Luna)** | **✗ 外側** |

</div>

<div class="text-center text-base opacity-80 mt-6">穴の名前は『運用・統制・経済』 — 皆様が20年磨いてきた領域</div>
