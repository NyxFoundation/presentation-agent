# エグゼクティブサマリー

<br>

| 項目 | 内容 |
|------|------|
| **What** | AIエージェントが自律的に取引を行い、DeFiプロトコルの改善点や脆弱性を発見する**テスト用L2 Rollup** |
| **Why** | 既存の静的解析や人間の監査では、MEV攻撃や複雑な経済的インセンティブの不整合など「動的な」脆弱性の発見が困難 |
| **Who** | 一般社団法人 Nyx Foundation（非営利型）主催 |
| **When** | 2026年後半（4フェーズで実行） |
| **Scale** | 参加100チーム ／ 賞金総額 100,000 USDC |
| **Value** | DeFiプロバイダーは自身のコントラクトをデプロイするだけで、AIによる24時間365日のストレステストを受けられる |
