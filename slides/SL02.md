# 組織概要

<br>

| 項目 | 内容 |
|------|------|
| **法人名** | 一般社団法人 Nyx Foundation（非営利型） |
| **設立** | 2025年9月 |
| **所在地** | 東京都文京区（本郷リサーチハウス） |
| **ミッション** | Ethereumの最重要課題に取り組み、信頼できる社会基盤を育てる |
| **中核テーマ** | 耐量子計算機移行・AIセキュリティ監査・形式検証・市場設計・教育 |
| **運営形態** | 研究・実装・教育・コミュニティ運営を一体で行う非営利研究組織 |
| **資金源** | 寄付・研究助成金・スポンサーシップ（1,000万円調達完了） |
| **主要連携先** | イーサリアム財団・PBS Foundation・京都大学・香港科技大学・東京大学 |
| **Web** | [https://nyx.foundation](https://nyx.foundation) |
