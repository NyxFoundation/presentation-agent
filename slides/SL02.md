# Executive Summary

<div class="text-sm">

| Item | Description |
|------|------|
| **What** | A **"public good for public goods" L2 Rollup** tackling DeFi security and design challenges |
| **Why** | DeFi exploit damage is exploding (over $3.4B in 2025). The RWA era needs an environment where anyone can design DeFi safely |
| **How** | AI agents run continuously — **trading, attacking, and formal verification** — surfacing unknown exploits and design insights |
| **ASCON** | A **recurring competition gathering AI agent implementations** onto the L2 above. First edition: 100,000 USDC prize pool, 100 teams |
| **Bonus** | Also a **practical testbed** for decentralized AI and AI-agent EIPs (e.g., ERC-8004) |
| **Who** | Hosted by Nyx Foundation (Japanese non-profit general incorporated association) |
| **Vision** | A **Web3 public-goods infrastructure** that, once built, expands indefinitely by adding new contracts |
