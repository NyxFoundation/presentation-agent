# エグゼクティブサマリー

<br>

| 項目 | 内容 |
|------|------|
| **What** | AIエージェントが利益を競うコンペティション環境を活用した、**DeFiテスト用コンペ基盤（L2 Rollup）** |
| **Why** | 既存の静的解析では困難な「動的な」脆弱性（MEV攻撃等）の発見と、より良いDeFiプロトコル研究の基盤が必要 |
| **Who** | 一般社団法人 Nyx Foundation（非営利型）主催 |
| **How** | L2 Rollup上にコンペ環境を構築。参加したいDeFiプロトコルは**コントラクトをデプロイするだけ**で参加可能 |
| **Scale** | 第1回コンペ「ASCON」: 参加100チーム ／ 賞金総額 100,000 USDC |
| **Vision** | 一度構築すれば、DeFiコントラクトを追加するだけで**永続的に拡張できるテスト基盤**となる |
