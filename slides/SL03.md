# まずは私たちのことを知ってください—Nyx Foundationは「理想の研究所」を目指す若手研究者集団です

- **設立の原点**: 2年前、研究所構想を議論した際、私たちが理想として掲げたのはSony創立趣意書の一文でした
  - 「真面目なる技術者の技能を、最高度に発揮せしむべき**自由闘達にして愉快なる理想工場**の建設」
- **価値観**: Ethereumは学歴・人種・年齢・所属にかかわらず**成果で評価される**エコシステム。その価値観に共鳴する少数精鋭の若手研究者・エンジニアで構成
- **活動拠点**: 本郷リサーチハウス（5名が居住しながら研究開発）を1年間運営中。南砺市に30名収容可能なラボを建設中
- **実績**: 30名以上のドナーから6,000万円以上の資金調達 / Fusaka監査で17件の脆弱性報告 / ZK Tokyo 4年目（Vitalik来訪） / 東大ブロックチェーン寄附講座と共同開催

### 技術研究実績（Application R&D）
- **価格参照契約**: 現実世界の契約をスマートコントラクト＋予測市場で自動化する理論構築
- **流動性供給分析**: LP（流動性供給者）ごとの損益を分析するダッシュボード開発
- **MEV分析**: プライベートメンプールでのJIT Liquidity・サンドイッチ攻撃等の影響を分析
