# OpenClaw のセキュリティモデル

<div class="grid grid-cols-2 gap-8">
<div>

## 設計上の信頼境界

- **API キー直渡し**: ホストマシン上で動くため OK
- **ツール実行**: サンドボックス内で制御
- **入力は信頼しない**: system prompt で制御
- **チャンネル接続**: Discord / Slack 等

</div>
<div>

## Trust Boundary

```
┌─────────────────────┐
│   ホストマシン（信頼）  │
│  ┌───────────────┐  │
│  │   OpenClaw    │  │
│  │  + API Keys   │  │
│  │  + Tools      │  │
│  └───────┬───────┘  │
└──────────┼──────────┘
           │ ← 信頼境界
    ┌──────▼──────┐
    │  Discord    │
    │  (untrusted)│
    └─────────────┘
```

</div>
