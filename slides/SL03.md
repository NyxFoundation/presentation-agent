## ポイント

- **インバウンドポート開放不要**
  - Gateway → Discord はアウトバウンドのみ
  - 外部からの侵入経路がない

- **APIキー平文保存はOK**
  - エージェントは復号コマンドも実行できる
  - ローカル暗号化は防御にならない
  - 流出時に disable する運用が正解

- **信頼境界の本質**
  - 制限は「エージェントが従う前提」のソフト制約
  - Docker sandbox のみがOSレベル強制
  - **→ つまり prompt injection に弱い**
