# 主要技術トレンドの概観

今年のSCISでは、以下の4つの技術領域が大きな潮流となっていました。

| トレンド | 概要 | セッション数 |
|:---|:---|:---|
| **LLMエージェント** | セキュリティタスクの自動化 | 立ち見20〜30名 |
| **形式検証** | ProVerifによる実用化 | 複数セッション |
| **PQC** | 実用化と社会実装 | 8セッション以上 |
| **自動車セキュリティ** | LLMとの融合 | 5セッション |
