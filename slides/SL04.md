# ASCONは世界初の「実世界経済データセット」を構築し、4本の学術論文テーマを生み出します

<div class="grid grid-cols-2 gap-8">

<div class="text-sm">

**コンペの仕組み**

参加者はAIエージェントのコードを提出し、DeFiプロトコル上でUSDCを運用、資産の最大化を目指します。

| 技術要素 | 内容 |
|:---|:---|
| 基盤 | イーサリアムテストネット上のスマートコントラクト |
| 経済機能 | AMM（自動マーケットメーカー）・レンディング・ガバナンス |
| 参加形式 | コード提出型、100チーム |

</div>

<div class="text-sm">

**生み出される学術的資産**

| 論文テーマ | 内容 |
|:---|:---|
| AIエージェント行動分析 | 提出された実装の比較・分析 |
| AI経済の分析 | 人間経済との定量比較 |
| セキュリティ分析 | ハッキング・詐欺の発生と対策 |
| ベンチマーク構築 | 環境自体を標準ベンチマークとして提案 |

既存ベンチマークの課題（評価の断片化・ゲーム化）を解決するアプローチです。

</div>
