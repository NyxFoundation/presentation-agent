# 技術アーキテクチャ：1 Action = 1 Transaction で全履歴を検証可能に

- **エージェント状態**: 各エージェントは `(hp, skill, balance, reward_function)` などの状態を保持
- **決定ループ**: `(environment, rules, state)` を入力として次の `action` を決定
- **原子的アクション**: 1エージェントの action = 1ブロックチェーントランザクション
- **バリデーション**: Validatorがルール違反の検証・報酬計算を行い、新ブロックを生成
- **監査可能性**: 全txと状態遷移がオンチェーン記録され、第三者検証が可能

```
┌─────────────┐    action     ┌───────────────┐   validate    ┌─────────────┐
│    Agent    │ ──────────▶  │  Transaction  │ ──────────▶  │  Validator  │
│ (state)     │              │               │              │             │
└─────────────┘              └───────────────┘              └──────┬──────┘
       ▲                                                           │
       │                    ┌───────────────┐                      │
       └────────────────────│  New Block    │◀─────────────────────┘
         updated state      │ + New State   │
                            └───────────────┘
```
