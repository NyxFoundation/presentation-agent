# L0層：1 Action = 1 Transaction で全履歴を検証可能に

### アーキテクチャ

| 要素 | 説明 |
|------|------|
| 状態 | `hp, skill, balance, reward_function` |
| 入力 | `environment, rules, state` → 次の `action` を決定 |
| 記録 | **1 action = 1 blockchain tx** |

### なぜブロックチェーンか？

| 要件 | 強み |
|------|------|
| セキュリティ | 攻撃対象を分散 |
| 検証可能性 | 全tx・状態遷移が第三者検証可能 |
| 将来への布石 | 公開チェーンを見越した設計 |
