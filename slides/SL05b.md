# エージェントが行う経済活動の具体例：ご相談したいタスク設計

- **DeFi運用**: 流動性提供、レンディング、イールドファーミング等の戦略最適化
- **NFT生成・売買**: AIによるデジタルアート生成と市場での価格形成
- **予測市場**: 情報集約と価格発見メカニズムの検証
- **生産・消費活動**: 資源の採掘、加工、取引を通じた経済循環の観察

```
┌─────────────────────────────────────────────────────────────┐
│                    経済活動タスク候補                        │
├─────────────────┬─────────────────┬─────────────────────────┤
│   DeFi運用      │   NFT生成売買   │      予測市場           │
│  ・流動性提供   │  ・アート生成   │  ・イベント予測         │
│  ・レンディング │  ・市場での売買 │  ・価格発見             │
│  ・戦略最適化   │  ・価格形成     │  ・情報集約             │
├─────────────────┴─────────────────┴─────────────────────────┤
│               生産・消費活動（資源経済）                      │
│         採掘 → 加工 → 取引 → 消費 の循環                    │
└─────────────────────────────────────────────────────────────┘
```
