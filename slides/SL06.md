# L1/L2層の研究課題：制度と主体の相互作用を探る

- **意図しない行動の制御（L2）**: AIエージェント経済において、市場操作や共謀などの有害な挙動をどうすれば検出・制御できるか？
- **規範の創発（L1↔L2）**: どのような制度設計（Institution Design）が、カルテルや非協力的な規範の創発を抑制するのか？
- **制度と主体の相互作用（L1↔L2）**: 制度設計（L1）と主体設計（L2）は相互にどう影響し合うのか？人間想定の制度はAI主体にも有効か？

