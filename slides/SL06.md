# 🦥 取引の遅延：世界コンピュータの応答速度

```mermaid
flowchart LR
  A[取引送信] -->|約12秒| B[ブロック提案]
  B -->|1-2分| C[高い確信]
  C -->|約6分| D[ファイナリティ]
```

::right::

**課題**
- 遅い確定時間によりUXが低下
- ブロックサイズ制限で混雑・高コスト化

**取り組み事例**
- Single Slot Finality (SSF)
- 3-Slot Finality（36秒確定の研究）

**研究テーマ**
- 分散システム：次世代コンセンサス設計
- アルゴリズム最適化：P2P伝播の高速化
