# 🦥 取引の遅延：世界コンピュータの応答速度

<div class="grid grid-cols-2 gap-6 mt-2 two-col-body">
  <div>
    <div class="mt-2">
```mermaid {scale: 0.85}
flowchart TD
  A[取引送信] --> B[メモリプール滞留]
  B -->|約12秒| C[ブロック提案]
  C -->|複数エポック| D[ファイナリティ]
```

<p><strong>課題</strong></p>
<ul>

  <li>ブロックサイズ制限で混雑・高コスト化</li>
</ul>

<ul>
  <li>Single Slot Finality (SSF)</li>
  <li>3-Slot Finality（36秒確定の研究）</li>
</ul>

<p><strong>研究テーマ</strong></p>
<ul>
  <li>分散システム：次世代コンセンサス設計</li>
  <li>アルゴリズム最適化：P2P伝播の高速化</li>
</ul>
