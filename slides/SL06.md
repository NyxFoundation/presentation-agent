# 🦥 取引の遅延：世界コンピュータの応答速度

<div class="mt-2">
```mermaid {scale: 0.85}
flowchart TD
  A[取引送信] --> B[メモリプール滞留]
  B -->|約12秒| C[ブロック提案]
  C -->|複数エポック| D[ファイナリティ]
```

<div class="right-content">

**課題**
- 遅い確定時間によりUXが低下
- ブロックサイズ制限で混雑・高コスト化

**取り組み事例**
- Single Slot Finality (SSF)
- 3-Slot Finality（36秒確定の研究）

**研究テーマ**
- 分散システム：次世代コンセンサス設計
- アルゴリズム最適化：P2P伝播の高速化
