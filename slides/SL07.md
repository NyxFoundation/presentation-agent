# 😈 MEVと検閲：公平性のゆらぎ

<div class="grid grid-cols-2 gap-6 mt-2 two-col-body">
  <div>
    <div class="mt-2">
```mermaid {scale: 0.8}
flowchart TD
  U[ユーザー取引] --> B[ブロック構築者]
  B --> R[リレー]
  R --> P[提案者]
  P --> C[チェーン]
  B -.->|並べ替え/抽出| X[MEV]
  R -.->|含めない| Y[検閲]
```
    </div>

<p><strong>課題</strong></p>
<ul>
  <li>MEVが経済インセンティブを歪める</li>
  <li>取引の選別・検閲リスクが増大</li>
</ul>

<p><strong>取り組み事例</strong></p>
<ul>
  <li>PBS（提案者と構築者の分離）</li>
  <li>MEV-Boostの普及</li>
</ul>

<p><strong>研究テーマ</strong></p>
<ul>
  <li>メカニズム設計：公正なオークション/報酬</li>
  <li>検閲耐性：包含リスト設計と検証</li>
</ul>
