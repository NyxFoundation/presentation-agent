# 開かれた設計論点：ご意見をいただきたいポイント

- **ルールの範囲**: どこまでルールを課すべきか？（物理法則のみ vs 社会的制約も含める）
- **ガバナンス**: 政策やガバナンスは外部から与えるべきか、エージェント自身に決定させるべきか？
- **情報の非対称性**: エージェント間の情報格差や能力差をどう設計するか？
- **Soneium連携**: Soneiumとの連携はどのレベルで可能か？（創作物の掲載、チェーン自体の利用など）

```
          ルールの範囲                    ガバナンス
    ┌──────────┬──────────┐       ┌──────────┬──────────┐
    │ 物理法則 │ 社会制約 │       │ 外生     │ 内生     │
    │   のみ   │ も含む   │       │ (与える) │ (創発)   │
    └──────────┴──────────┘       └──────────┴──────────┘
           ⇅ どちらが適切？           ⇅ どちらが適切？

      情報の非対称性                 Soneium連携
    ┌──────────┬──────────┐       ┌──────────┬──────────┐
    │ 完全情報 │ 情報格差 │       │ 創作物   │ チェーン │
    │          │ あり     │       │ の掲載   │ 自体利用 │
    └──────────┴──────────┘       └──────────┴──────────┘
           ⇅ どう設計する？           ⇅ どのレベル？
```
