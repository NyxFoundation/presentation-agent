# PSE's research problems—from anonymous signaling to private voting to post-quantum signatures—require exactly the expertise this room possesses.

- Semaphore: anonymous group signaling with double-spend prevention—requires efficient ZK proof construction
- MACI: minimal anti-collusion infrastructure for private voting—requires formal verification and cryptanalysis
- ZK Email: privacy-preserving email verification using DKIM signatures—novel protocol design challenge
- Post-quantum migration: lattice-based proof systems, hash-based signatures, FHE key management

<!-- Speaker Notes:
Let me make this concrete with a single example that illustrates the depth of these problems.

Semaphore is an anonymous signaling protocol that lets users prove group membership without revealing identity—while preventing double-signaling. The core challenge is efficient zero-knowledge proof construction with robust security guarantees. This is not a simplified problem. It requires the same formal security analysis, the same careful construction, the same rigorous verification that characterizes top-tier cryptographic research.

PSE maintains similar active research programs in several areas: MACI, the Minimal Anti-Collusion Infrastructure, enables private voting resistant to bribery and requires formal verification of the cryptographic protocol. ZK Email allows privacy-preserving verification of email authenticity using existing DKIM signatures—a novel protocol design problem. And the post-quantum migration challenge—moving these systems to lattice-based primitives—is perhaps the most urgent open problem in deployed cryptography today.

These are frontier research questions with immediate applications—exactly the kind of work where Japanese cryptographic expertise could make significant contributions.
