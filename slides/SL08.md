# コンペ開催後の研究プラン

| Phase | 研究成果 | 先行研究 | 新規性 | 想定実用先 |
|:--|:--|:--|:--|:--|
| ① 第1回で出る | **多役経済行動ログデータセット** | StockBench (2025) / AI-Trader (2025) / AMA (2025) / StockAgent (2024) — いずれも trader 単独の取引ログ | **trader × hacker × verifier が同一台帳で共存する初のログ**。攻撃tx・監査artifact・通常取引が単一の時系列で結合 | **NeurIPS**, 企業内エージェント開発・評価データとして |
| ① 第1回で出る | **暗号資産市場上の多役評価ベンチマーク** | AgentBench / R-Judge, Cybench / NYU CTF Bench / DARPA AIxCC, StockBench / AMA — 各役割を個別評価 | **暗号資産市場上で 複数戦略AI を同時評価する初の実践的ベンチマーク** | **ICLR Benchmark, USENIX Security**, AIエージェント導入前評価の業界標準として |
| ② 発見駆動 | **AI攻撃者による事前DeFi脆弱性発見** | SoK: DeFi Attacks (Zhou 2023) / TxRay (2026) / FlashSyn (2024) / LookAhead (2024) — いずれも事後分析・履歴上の合成攻撃 | **新規プロトコル/構成に対する脆弱性レポートとその発見方法論** | **USENIX Security / CCS**, セキュリティ監査として |
| ③ 縦断 | **金銭が実インセンティブの経済での AI 共謀・欺瞞の縦断分析** | Colosseum (2026) / NARCBench (2026) / MAEBE (2025) / Emergent Social Intelligence Risks (2026) — いずれも DCOP / blackjack / RPG など抽象タスクでの観察 | **金銭が実インセンティブとして作用する経済**での自然発生現象を年次反復で蓄積する初の縦断データセット | **NeurIPS, ICML**, マルチエージェントシステムの統制・ガバナンス設計として |
| ③ 縦断 | **AIエージェント権限設計の経済最適化ベンチマーク** | AgenTRIM (2026) / Agent-SafetyBench (2024) / ToolSafe・WebGuard (2025) / EU-Agent-Bench (2025) — いずれも固定権限でのガードレール評価 | **権限設計そのものを最適化変数**として扱い、利益と最大損失の経済結果から最適境界を逆算する初のベンチ | **USENIX Security / S&P**, 業務AIエージェントの権限ポリシー設計として |
