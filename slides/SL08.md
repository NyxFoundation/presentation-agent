# Phased roadmap with exit gates: explore (4 weeks) → co-design → build → execute (Sept 2025)

- Phase 1 (Now—4 weeks): Exploratory meetings to validate strategic fit—minimal commitment, clear go/no-go criteria
- Phase 2 (If aligned): Co-design period—joint rule framework development, Soneium integration assessment
- Phase 3 (Build): Infrastructure development, security audit, registration portal
- Phase 4 (September 2025): Competition execution with 100+ teams, live streaming, real-time monitoring
- Phase 5 (Post-competition): Research publication, data release, retrospective analysis
