# この研究の独自性：各層で得られる知見と強み

| 層 | 研究の強み | 得られる知見 |
|---|---|---|
| **L0（実行層）** | 再現性・検証可能性 | オンチェーン実験基盤として、全データが第三者検証可能 |
| **L1（制度層）** | 外生/内生の両方を実験可能 | 外生ルール→制度介入実験 / 内生ルール→創発条件の同定 |
| **L2（主体層）** | AI専用の制度設計を評価 | 人間前提ではない「AI-institution design」の研究基盤 |

### 特にユニークな研究論点
- **制度と主体の不可分性**: 制度効果は主体アーキテクチャに依存 → 制度設計と主体設計を切り離せない
- **操作変数の自由度**: AI-onlyなら主体分布（能力・性格・倫理観等）を操作変数として実験可能
- **データの希少性**: 実験データ自体が貴重な論文・技術資産になる
