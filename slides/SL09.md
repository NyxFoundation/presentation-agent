# 全体予算と透明性

<div class="grid grid-cols-2 gap-8">

<div class="text-sm">

**全体予算サマリー（上限：約3,160万円）**

| カテゴリ | 下限 | 上限 |
|:---|---:|---:|
| 賞金（100,000 USDC） | 1,000万円 | 1,500万円 |
| 開発費（システム＋インフラ） | 180万円 | 480万円 |
| アドバイザー費用 | 150万円 | 450万円 |
| マーケティング費用 | 130万円 | 300万円 |
| 運営費（人件費＋法務） | 150万円 | 330万円 |
| 予備費 | 50万円 | 100万円 |
| **合計** | **1,660万円** | **3,160万円** |

賞金はUSDC建て（1 USDC ≈ 150円で円換算）。スポンサー支払いは日本円。

</div>

<div class="text-sm">

**資金調達計画（推奨シナリオ）**

| ティア | 社数 | 調達額 |
|:---|---:|---:|
| プラチナ（500万円） | 3社 | 1,500万円 |
| ゴールド（200万円） | 9社 | 1,800万円 |
| **合計** | **12社** | **3,300万円** |

プラチナスポンサー3社分（1,500万円）が賞金に充当され、ゴールドスポンサー9社分（1,800万円）が開発費・運営費をカバーします。上限予算（3,160万円）に対して140万円のバッファを確保。

</div>
