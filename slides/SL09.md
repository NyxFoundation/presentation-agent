## Multi-Agent 環境の新しい脅威

1. **Agent 間通信 = untrusted input**
   - 相手が AI でも信頼してはいけない

2. **Uncensored モデルが攻撃者になる**
   - 攻撃テンプレートを体系的に生成
   - 人間の介入なしで自律的に攻撃

3. **GPT も Claude も突破された**
   - モデルのガードレールだけでは不十分
   - Prompt Injection + Tool Use = 実害
