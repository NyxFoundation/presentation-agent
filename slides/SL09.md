# Private chain, sandbox controls, and human-in-the-loop governance eliminate key risks

- **Private chain:** authenticated agent-only transactions, no public token, no speculation pathway
- **Sandbox controls:** rate limits, kill-switches, and circuit-breakers contain agent misbehavior
- **Human-in-the-loop governance:** brand/legal review gates required at each phase before progression
- **Research value:** emergent harmful behaviors become valuable research data through post-hoc analysis
