# S1-C. 3つの社会的需要 — なぜ「今」社会実装なのか

<div class="grid grid-cols-3 gap-4 mt-4 text-sm">

<div class="rounded-xl border border-purple-300 p-4">
<div class="text-xs text-purple-700 tracking-widest">DEMAND ①</div>
<div class="text-lg font-bold mt-1">AI 時代の<br/>セキュリティ・プライバシー</div>
<ul class="mt-3 text-xs text-gray-700 space-y-1">
<li>• AI agent identity (IETF 関連ドラフト群で議論中)</li>
<li>• <strong>Proof-of-Exploit</strong></li>
<li>• Verifiable AI inference (<strong>zkML</strong>)</li>
<li>• Private inference (FHE-LLM / Concrete ML)</li>
<li>• 連合学習 (<strong>mpcML</strong>)</li>
</ul>
<div class="mt-3 italic text-xs text-purple-800">
"医療データを診断 AI に預けても、データが保持されないと<strong>検証</strong>できる" (FHE+ZK)
</div>
</div>

<div class="rounded-xl border border-green-300 p-4">
<div class="text-xs text-green-700 tracking-widest">DEMAND ②</div>
<div class="text-lg font-bold mt-1">プライバシー × <br/>コンプライアンス両立</div>
<ul class="mt-3 text-xs text-gray-700 space-y-1">
<li>• 「全公開 ⇔ 全秘密」二項対立の超越</li>
<li>• <strong>EU 年齢確認義務</strong> → Google Longfellow OSS化 (2025/7)</li>
<li>• Sparkasse 提携 / Bumble 認証稼働</li>
<li>• DeFi <strong>サンクションリストに載っていない</strong>を ZK 証明 (Privacy Pools)</li>
</ul>
<div class="mt-3 italic text-xs text-green-800">
"海外でマイナンバーカードを使ってログインできる時代" (Longfellow)
</div>
</div>

<div class="rounded-xl border border-amber-300 p-4">
<div class="text-xs text-amber-700 tracking-widest">DEMAND ③</div>
<div class="text-lg font-bold mt-1">Ethereum <br/>スケーリング = 効率</div>
<ul class="mt-3 text-xs text-gray-700 space-y-1">
<li>• L2 手数料の構成: <strong>proving cost</strong> が支配的になる場面が多い</li>
<li>• Sumcheck / Jolt で 2× 高速化 → ユーザ手数料に直結</li>
<li>• folding/IVC で「積み上がる計算」を圧縮</li>
</ul>
<div class="mt-3 italic text-xs text-amber-800">
研究の高速化 ≠ ベンチマーク勝負、<strong>ユーザの体感コスト</strong>が下がる
</div>
</div>

</div>

<div class="mt-4 rounded-xl border border-gray-300 bg-gray-50 p-3 text-xs">

⚖️ <strong>倫理的注</strong>: プライバシー保護は<strong>合法的取引も非合法な活動も同じく覆い隠す</strong>。Tornado Cash の OFAC 制裁 (2022) は実例。Privacy Pools のような <strong>"規制対応プライバシー"</strong> がこの緊張を解く方向性。Programmable Cryptography は中立的なツール — <strong>何を可能にするか</strong>と<strong>何を防ぐべきか</strong>を同時に設計する。

</div>

<div class="mt-2 text-[10px] text-gray-500">

「社会実装」= 暗号技術が研究室から出て社会的取引・行政・金融サービスで稼働している状態 (deployment / real-world cryptography)。

</div>
