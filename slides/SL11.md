# 🕹️ ユースケースの偏在：DeFiという巨大な引力

| 区分 | 内容 |
|:---|:---|
| **現状** | ・全スマートコントラクト活動の約90%が金融取引 (DeFi) <br>・NFTも金融的側面が強い |
| **課題** | ・金融以外の社会インフラ（投票、ID管理等）への応用が限定的<br>・現実世界の経済活動との接続が弱い |
| **解決策** | ・分散型科学 (DeSci)<br>・分散型ソーシャルメディア (Farcaster)<br>・予測市場 (Polymarket) |
| **研究テーマ** | ・インセンティブ設計<br>・ガバナンスモデル<br>・社会システムとのインターフェース研究 |
