# 🕹️ ユースケース：契約の拡張

```mermaid
flowchart LR
  A[金融契約] --> B[一般契約]
  B --> C[売買]
  B --> D[業務委託]
  B --> E[ライセンス]
```

::right::

**課題**
- 金融以外の契約設計が未成熟
- 社会制度との接続が弱い

**取り組み事例**
- リアルワールドアセットの実験
- オンチェーン契約管理の試行

**研究テーマ**
- 契約理論：インセンティブと自動執行
- 法学×暗号：境界条件の設計
