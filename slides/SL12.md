Speaker Notes:

【概要】
S1 の最後に「証明 (proof)」という言葉の 3 つの意味を整理する。これは S2 以降で「ZK 証明」を扱うときの土台になる前提。混同を避けたいのは「ZK 証明は数学的に正しい」という言い方 — これは厳密ではない。

【3 つの「証明」】
①  数学的証明 (mathematical) — formal logic と公理系から命題を導出する。peer-review で人類が共有。例: フェルマー予想 (Wiles 1995)、ゲーデルの完全性/不完全性。本講義の射程外。Pr[wrong] = 0、時間に依らない。
②  情報論的暗号証明 (information-theoretic) — 敵対者が ∞-compute (無制限な計算能力) を持っていても、確率 1 で破れない。例: One-Time Pad (Shannon 1949)、Σ-protocol の perfect soundness。理論的に最強だが、鍵長・通信量が現実的でないことが多い。
③  計算論的暗号証明 (computational) — 敵対者が poly-time (多項式時間) であることを仮定し、加えて DL (離散対数) / RSA / LWE 等の hardness assumption の下で偽造不可能。例: デジタル署名、MAC、SNARKs (Sumcheck/Jolt)、Longfellow。2026 年の社会実装はほぼすべてここ。

【各 phase の物語】
phase 0 — 3 panel が並ぶ。淡色で intro。3 概念を予告。
phase 1 — ① のみ active (紫)。Axioms → Lemma → Theorem の derivation chain が光る。QED stamp が pulse。敵対者なしの note を表示。
phase 2 — ② のみ active (teal)。wire 上に「π = 0xA4 7B 3F … 9E 2D」と「proof = 大きな数字」を可視化。Verifier 右上に ✓ chip、その下に「g^z ≡ a · y^c → ✓」(Σ-protocol 検証ロジック) を表示。下に Adversary (∞ symbol pulse) と「→ ✗ break impossible」。
phase 3 — ③ のみ active (amber)。同じ構造で「π = 0x7a3f c8e2 d4 … b14e」(SNARK proof = 大きな数字) が wire に出る。Verifier の検証ロジックは「e(a, b) ≡ e(g, vk) → ✓」 (pairing check)。Adversary は clock icon (poly-time) で tick、「→ ✗ negl(λ)」。「⚠ assuming: DL · RSA · LWE hard」badge 出現。
phase 4 — ③ が gold border に強調 + 「★ 2026 社会実装はすべてここ」callout。①② はそのまま dim。S2 (ZK/MPC/FHE) への橋渡し。

【「証明」の実体の可視化】
②③ で wire に表示している hex は「暗号証明の実体は大きな数字 (group element / hex string)」を視覚化したもの。Verifier の下に出る式 (`g^z ≡ a·y^c` / `e(a,b) ≡ e(g,vk)`) は「Verifier が特定のロジックを実行して結果が ✓ になれば accept」という構造。proof は意味のある object ではなく、verifier の equation を満たすかどうかだけが本質。

【講義での強調点】
- "ZK 証明は数学的に正しい" は厳密でない。① と ③ を混同しない。計算量仮定が破れれば protocol も破れる。
- ② と ③ の構造はほぼ同じで、違いは「敵対者の計算量」と「仮定が必要かどうか」の 2 点だけ。視覚的に Panel 2 (∞) と Panel 3 (clock + DL hard badge) を並べて見せる。
- 暗号証明は「Verifier が固定の equation を check して通れば OK」だけ — π という大きな数字が equation を満たす能力だけが意味を持つ。これが ZK の構造的特徴 (S2-A の伏線)。
- ① は本講義の射程外だが、混同を防ぐために置いた。Wiles の Fermat 証明は紙とインクで peer-review されたもので、暗号と無関係。
- 2026 年: 量子計算機が成熟すれば RSA・ECDSA など多くの ③ が崩れる。だから lattice (LWE) 系や hash 系 (FRI / Brakedown) への移行が進む。"③ に賭ける" は永続ではなく "現時点で最良" という意味。
- S2 の橋渡し: 次から ZK / MPC / FHE を見ていくが、すべて ③ の系譜。仮定下で偽造不可能。仮定を選び・組み合わせる設計が programmable cryptography の中身。
