# 研究テーマリスト（RFPs）

<div class="text-xs mt-2">

| Tier | テーマ | 概要 |
|:---:|:---|:---|
| **0** | **Trust Assurance Framework** | ZK/TEE/MPCの信頼仮定を比較する標準フレームワーク |
| **0** | **Benchmark Dashboard** | プライバシーL2の性能を週次で自動検証 |
| 1 | Custody Controls SDK | 機関向け鍵管理・承認ワークフロー・監査ログSDK |
| 1 | Privacy Pools Integration | OFAC対応のコンプライアンスフレンドリーなプライバシー |
| 2 | RPC Privacy | ノードへのRPCクエリに対して取引内容を秘匿する機能 |
| 2 | zk-SPV for DvP | ZKを活用したプライベートなクロスチェーン決済 |
| 2 | Compliance Primitives Toolkit | Travel Rule・KYC/AML対応のZK認証ツールキット |

</div>
