# S2-B. 主要な合成パターン — <strong>7つの組み合わせ</strong>と例

<table class="text-xs mt-2">
<thead>
<tr><th class="w-1/4">合成パターン</th><th class="w-2/5">何が合成されているか</th><th>例 / 状態</th></tr>
</thead>
<tbody>
<tr>
<td><strong>ZK over 既存暗号</strong></td>
<td>既存暗号 (ECDSA, SHA-256) on identity standards (mDOC, JWT, W3C VC) を ZK 化</td>
<td><strong>Longfellow</strong> (Google, OSS 2025/7)</td>
</tr>
<tr>
<td><strong>ZK + FHE</strong></td>
<td>計算秘匿 + 計算正しさ</td>
<td>Verifiable FHE</td>
</tr>
<tr>
<td><strong>MPC + FHE</strong></td>
<td>鍵分散 + 計算秘匿</td>
<td>threshold FHE (Zama, NIST 提出)</td>
</tr>
<tr>
<td><strong>ZK + ML</strong></td>
<td>推論 + 検証</td>
<td>zkML (EZKL, ezkl-poc 系)</td>
</tr>
<tr>
<td><strong>MPC + ML</strong></td>
<td>学習 + 入力秘匿</td>
<td>mpcML (連邦学習)</td>
</tr>
<tr>
<td><strong>ZK + Multisig</strong></td>
<td>操作 + 認証</td>
<td>proof of multisig operation (Nyx)</td>
</tr>
<tr>
<td><strong>ZK + Bridge</strong></td>
<td>cross-chain message + state proof</td>
<td>ZK light client (詳細 S2-C)</td>
</tr>
</tbody>
</table>

<div class="mt-4 grid grid-cols-2 gap-3 text-xs">

</div>
