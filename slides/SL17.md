Speaker Notes:

【概要 (線は 1 本だけ)】
- 1992 年の Sumcheck から 2025 年の Jolt まで、prover 性能の 30 年を 1 本の線で降りてくる。
- 破線区間 (1992-2016) = 理論のみの時代。Sumcheck (LFKN 1992)、GKR (2008) は白抜きダイヤ — 実装が無くオーバーヘッド計測が存在しない。
- 実線区間 (2016-) = 実装の最速 prover オーバーヘッド (native 実行の何倍遅いか, log。下ほど速い): Groth16 → Spartan / Nova (Microsoft) → RISC Zero → SP1 → Jolt。10 年で 10⁶-10⁷ 倍 → 10⁵ 倍未満 = 2 桁の高速化。
- 右上の Longfellow (Google, 2024) は zkVM と別指標 (mDL 提示証明を スマホで数百 ms) のため線に乗せず併記。
- 注: Spartan / Nova の点は系譜上の中継点で、公表オーバーヘッド値があるわけではない (位置は模式)。数値アンカーは Groth16 / 現行 FRI 世代 / Jolt の 3 つ (Thaler a16z 分析 + Jolt 公表値)。

【点の色 = 系統 (混同しないのが本日の要点)】
- グレー = pairing 系: Groth16 (2016)。証明は最小 (~200B)・検証最速だが、trusted setup が必要で prover オーバーヘッドが大きい (Thaler の分析で 10⁶-10⁷ 倍相当)。Groth16 は Sumcheck 系ではない。
- 青 = STARK / FRI 系: hash ベースで trusted setup 不要・耐量子。RISC Zero、SP1 (Turbo まで)。zkVM を最初に実用化した系統だが、オーバーヘッドは ~10⁶ 倍で横ばいだった (Thaler, 2025/3: 「1 年前とほぼ同じ」)。StarkWare Stwo (circle STARK) も同系統で Starknet mainnet 稼働 (2025)。
- amber = Sumcheck 系: Jolt (a16z)。2025/8 に prover オーバーヘッド 10⁵ 倍未満・ラップトップ単体で 500 kHz 超 (32 コアで 1 MHz 超) を公表 — 他 zkVM 比で 1 桁改善。SP1 も Hypercube (2025/5) で univariate STARK から Sumcheck 系 (multilinear + LogUp GKR) に全面刷新して real-time proving を達成 (p8 のグラフの正体)。
- シェルフ上の Spartan / Nova は Microsoft Research (Setty ら) の transparent SNARK / folding の系譜 — Sumcheck 系理論の実装可能性を切り拓いた中継点。
- Longfellow (Google) は Ligero + Sumcheck を既存 ID にそのまま適用した別出口: mDL の ECDSA + SHA-256 署名を発行者側の変更ゼロで ZK 化。スマホ実測で ECDSA 証明 ~20ms、mDL 提示証明は数百 ms (eprint 2024/2010)。Google Wallet で 2025 年から稼働、Trail of Bits + Ligero の監査済み OSS。zkVM とは解く問題が違うためオーバーヘッド軸には乗せずシェルフ側に置いている。

【物語 (口頭)】
2016 年の Groth16 は「証明は小さいが作るのが遅い、しかも回路ごとに儀式 (trusted setup) が要る」世界だった。STARK 系が setup を消して zkVM を実用化し、Sumcheck 系がオーバーヘッドの壁を破った。並行して MPC-in-the-head 系は「既存の身分証をそのまま ZK 化する」という別の出口から社会実装に到達した。系統 (仮定・数学) が違えば得意な出口も違う — S3 の技術選定 (p19 の 4 つの問い) の土台になる見取り図。

【数値の扱い (質問されたら)】
- オーバーヘッド値は Justin Thaler (a16z) の公表分析と Jolt チームの公表ベンチに基づく。ベンチマークは witness 生成を含むか等で大きく変わる (罠 #4) ので、桁 (オーダー) だけを読む。
- Groth16 の 10⁶-10⁷ は「バックエンド ~100×|C| 群演算 + frontend の回路化コスト」を合わせた Thaler 2022 の分析値で、単一の実測論文値ではない。
