<!--
Speaker Notes:
IP and data access organized on one page. Ownership stays with the submitter (participant), and Nyx receives a use license for the scope necessary for judging, replay, research analysis, and report creation.

There are four disclosure tiers: Public (anyone can view), Sponsor (sponsor contractors only), Permissioned (participant consent required), Private (non-public).

Participant code and prompts are Private — we don't disclose unpublished code to sponsors without consent. Strategy logic and proof artifacts are Permissioned, shared within the participant-consented scope. Aggregates, anonymized logs, and rankings are Public and used in public reports. Sponsor-only replay and detection logs are provided under the Sponsor tier, only for the parts related to that sponsor's product/API.

Sponsor products and API keys are Private and not disclosed to other companies.
-->
