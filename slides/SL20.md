Speaker Notes:
【概要】ZK 系の進化を「commitment scheme」と「proving system」の 2 軸で並べる。現代 zkVM は両軸の組み合わせとして実装されている。folding 単体ではなく、より広い proving system 軸として STARK / Jolt / HyperNova までカバー。

【図の読み方】2 つの timeline。
- 上トラック (commitment): KZG (2010) → FRI (2017) → Brakedown (2023) → BaseFold / Binius / WHIR (2024)
- 下トラック (proving system): Groth16 (2016) → STARK (2018) / PLONK (2019) → Halo2 (2020) → Nova (2022) → Jolt / HyperNova (2024)
- 色は era 区分: 赤 = classic (pairing/trusted setup), 緑 = hash-based 系譜, 水 = modern (2024+)
- 下のストリップに現代 zkVMs (Jolt / SP1 / RISC0 / Nexus) と各々の組み合わせ recipe

【講義での強調点】
- <strong>commitment 軸</strong>: KZG (pairing, trusted setup) → FRI (hash, transparent) → Brakedown (linear-time) → 2024 で BaseFold / Binius / WHIR が登場
  - BaseFold (CRYPTO 2024): multilinear + field-agnostic、HyperPlonk 向けに concretely efficient
  - Binius: binary tower の small field PCS、Irreducible / Diamond & Posen 開発
  - WHIR: Reed-Solomon proximity testing でとても速い verifier
  - FRI-Binius: BaseFold + Binius のハイブリッド (2024)
- <strong>proving system 軸</strong>: Groth16 (pairing) → STARK (FRI) と PLONK (KZG) が並走 → Halo2 で accumulation/recursion → Nova で folding scheme (IVC) → Jolt (sumcheck + Lasso lookup) → HyperNova / ProtoStar / CycleFold (folding evolution)
  - Jolt (a16z crypto, 2024): SNARK for RISC-V VMs via lookups。Twist & Shout (2025) で memory checking を強化
  - HyperNova (Kothapalli & Setty 2023): multi-folding generalization
  - ProtoStar (Bünz & Chen 2023): generic folding for special-sound protocols
  - CycleFold (Kothapalli & Setty 2024): cycle of curves で folding を軽量化
- <strong>現代 zkVMs はこれらの組み合わせ</strong>:
  - Jolt = Sumcheck + Lasso (将来 Binius / Zeromorph 対応予定)
  - SP1 = Plonky3 + FRI (Succinct Labs)
  - RISC0 = STARK + FRI
  - Nexus = HyperNova + CycleFold

【講義での補足】
- folding (Nova 系) は proving system の中の「recursion / IVC」サブ軸 — 切り出さず proving system 軸の流れの中に置く
- 「2024 が転換点」: 古い SNARK 常識 (R1CS + pairing + trusted setup) から、sumcheck-based + small-field + foldable commitment の世界へ
- ベンチマーク 2025: Jolt が RISC0 比で 5x、SP1 比で 2x 速い場面あり (preliminary)。proof size は今 3-10 MB だが Zeromorph 対応で数十 KB へ縮む予定
- 注: 図中の年は paper 公開年 (production deployment にはラグあり)
