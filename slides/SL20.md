# リスクと対応策

| リスク | 対策 |
|--------|------|
| **エージェント暴走** | ネットワーク完全隔離 + Kill Switch + VLAN物理分離 |
| **データ悪用** | 研究機関限定アクセス + NDA + 利用規約 |
| **スポンサー不足** | 最低実施ライン設定（賞金1,000万円）、規模縮小対応 |
| **法的リスク** | 弁護士意見書事前取得、不正アクセス禁止法非該当を明文化 |
| **「攻撃助長」批判** | 非営利主催 + 倫理委員会 + 省庁後援 |

<br>

<div class="p-3 bg-gray-50 text-sm">

全リスクに対して事前の軽減策を設計済みです。特に法的リスクについては、弁護士意見書を事前に取得し、不正アクセス禁止法への非該当性を明文化する予定です。

</div>
