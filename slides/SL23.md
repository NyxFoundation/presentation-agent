# S2-D. ライブデモ — <span class="text-amber-700">運転免許証がそのまま ZK 化される</span>

<div class="grid grid-cols-2 gap-6 mt-2">

<div>

### デモシーケンス (実演)

<ol class="text-sm list-decimal pl-5 space-y-2 mt-2">
<li>スマホ画面をスクリーンにミラーリング</li>
<li><strong>Google Wallet</strong> の年齢証明 UI を開く</li>
<li>検証サイトが <strong>"≥18"</strong> を要求 (QR 読み取り 1 回)</li>
<li>Wallet が ZK proof を生成 (数秒) → 検証サイトが verify → 通過</li>
</ol>

<div class="mt-4 bg-white rounded-xl border border-gray-200 shadow-sm p-3 text-sm">

<strong>観察ポイント</strong>:
<div class="mt-1 space-y-1">
<div><span class="text-amber-500">&#9654;</span> 運転免許証の<strong>生年月日は一切送信されていない</strong></div>
<div><span class="text-amber-500">&#9654;</span> 署名は<strong>政府発行のまま</strong> — Issuer 側は何も変えていない</div>
<div><span class="text-amber-500">&#9654;</span> UX は QR コード読み取り 1 回だけ</div>
</div>

</div>

<div class="mt-4 bg-amber-50 rounded-xl border border-amber-200 p-4 text-sm">

<strong>Take-away</strong>: これが Programmable Cryptography の社会実装の現在地。「秘密と公開の二項対立」を超えた<strong>選択的開示</strong>の現実例。
