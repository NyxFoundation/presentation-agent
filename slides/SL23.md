# S2-D. Longfellow ライブデモ — <strong>運転免許証がそのまま ZK 化される</strong>

<div class="grid grid-cols-2 gap-6 mt-2">

<div>

### デモシーケンス

<ol class="text-sm list-decimal pl-5 space-y-2">
<li>スマホ画面ミラーリング: <strong>Google Wallet</strong> の年齢証明 UI を開く</li>
<li>検証サイト (Bumble など) で <strong>"≥18"</strong> を要求</li>
<li>Wallet が ZK proof を生成 (数秒)</li>
<li>検証サイトが proof を verify → 通過</li>
</ol>

<div class="mt-4 rounded border border-gray-300 p-3 text-sm">

<strong>観察ポイント</strong>:
<ul class="mt-1 list-disc pl-5">
<li>運転免許証の<strong>生年月日は一切送信されていない</strong></li>
<li>署名は<strong>政府発行</strong>のまま、何も変えていない</li>
<li>UX は QR コード読み取り1回だけ</li>
</ul>

</div>

</div>

<div class="flex flex-col items-center justify-center">

<div class="text-7xl font-bold text-black">"≥18"</div>
<div class="text-xl text-gray-500 mt-3">だけが伝わる。</div>

<div class="mt-8 max-w-sm rounded-xl border border-amber-300 bg-amber-50 p-4 text-sm">

🎯 <strong>Take-away</strong>: <br/>
これが Programmable Cryptography の<strong>最高の社会実装</strong>。「秘密と公開の二項対立」を超えた、<strong>選択的開示</strong>の現実例。

</div>
