# SCIS2026参加 目的と成果サマリー

今回の学会参加では、以下の3つの目的を掲げて活動しました。

| 目的 | 成果 |
|:---|:---|
| **1. 研究成果の公表とフィードバック獲得** | ・監査コンテストにおける脆弱性発見アプローチを発表<br>・AIによる定理証明自動化に関する研究成果を発表<br>→ 第一線の研究者から多数の質の高いフィードバックを獲得 | 
| **2. Nyxのプレゼンス向上と技術的優位性の発信** | ・論文発表に加え、ナイトセッションでNyxの活動を広く周知<br>・サイドイベント開催により、研究者コミュニティにおけるNyxのブランドを確立 | 
| **3. 研究者ネットワークの構築と協業機会の模索** | ・国内外の主要な研究者・組織と関係を構築<br>・特に、イーサリアムエコシステムに関心を持つ研究者との繋がりを強化 | 

**総括:** 論文発表に留まらず、戦略的なネットワーキングとイベント開催を通じて、当初の目的を大きく上回る成果を達成できました。
